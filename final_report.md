6. Task 3: Secure Coding Review

6.1 Objective

To inspect a sample Python application, identify insecure coding patterns, and recommend remediation measures.

6.2 Technologies Used

Python, Flask, SQLite, and manual source-code inspection.

6.3 Implementation

A demonstration Flask application was reviewed using manual inspection and a basic Python pattern-checking script.

The review examined the following issues:

Hardcoded application secrets.

SQL queries constructed using string concatenation.

Debug mode enabled in the development server.

6.4 Security Recommendations

Store application secrets in environment variables or a suitable secret manager.

Use parameterized SQL queries to reduce SQL injection risk.

Disable debug mode in production environments.

Review and retest the application after applying fixes.
